# QR Code Reservation System

Ever needed to reserve a room with just a quick scan of a QR code? This project makes that possible.

This repository contains the full codebase for my dynamic room reservation system — including both the frontend interface and backend server — designed as a real-world web application for Arkansas Tech University.

It was built from the ground up as an entry-level engineering project, and serves as both a technical showcase and a practical system that can be deployed for university use.
